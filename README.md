# C-tool

AI 맞춤 보장분석 & 비교 시뮬레이터 빌더 (단일 HTML 앱)

## 실행 방법
별도 빌드 과정이 없습니다. `index.html`을 브라우저(Chrome 권장)로 열면 바로 동작합니다.

- 인터넷 연결 필요: Tailwind CSS / Google Fonts CDN, Gemini API 호출
- Gemini API 키는 브라우저 localStorage에만 저장됩니다.
- [고객용 한눈에 보장 다운로드] 버튼으로 고객에게 전달할 독립 HTML 파일을 생성합니다.

## 서류 파싱 / 현황 분석
- 파일을 넣는 **즉시 자동으로 읽기 시작**하고(AI 연결이 안 되어 있으면 연결·키 입력 후 자동 시작), 마지막 [통합 생성] 버튼은 이미 읽은 결과를 모아 분석만 합니다.
- 업로드한 파일을 **파일별로 병렬(3개 동시) 읽고**, 파일마다 진행 상태·문서유형(기존 증권/신규 설계서)·계약/담보 수·확신도·소요시간을 표시합니다. 문서유형은 파일별로 직접 바꿀 수 있습니다.
- 큰 사진은 업로드 전 자동 축소하고, 일시 오류(429/503)는 자동 재시도하며, 모델명이 없으면 사용 가능한 flash 모델로 자동 전환합니다.
- 고객용 리포트는 맨 위 **계약현황 요약** 아래에 탭이 있습니다: **🚦 보장분석신호등**(다섯 친구/신호등, 담보별 진단현황) · **📁 계약·담보 현황**(보유 계약현황, 상품별 가입담보 상세) · **🏥 실손의료비** · **⚖️ 계약·비교**. 기존/신규 체크박스를 바꾸면 즉시 다시 계산됩니다.
- **🏥 실손의료비** 탭은 「실손의료비 변천사」 자료(표준화 이전·1~3차·착한실손·4세대·5세대)를 내장합니다. 실손 계약의 계약일로 **가입 세대를 자동 계산**해 탭 맨 위 **"고객 실손의료비 가입 세대"** 칸에 크게 보여주고(가입 후 경과 기간과 다음 재가입 시기도 표시)하고(기본 정보에서 세대를 직접 지정할 수도 있음), 그 세대의 설명, 5세대로 바꿀 때 좋아지는 점·불리해지는 점, 항목별 비교표를 보여줍니다. 세대 칩을 눌러 다른 세대도 볼 수 있습니다. 증권에서 읽은 실손 담보(입원·통원, 비급여 도수·주사·MRI 특약)와 보험료를 **👤 고객 가입 내용**으로 보여주고, 가입한 특약에 따라 5세대 전환 핵심 포인트(예: 도수치료 특약은 5세대에서 보장 제외)를 고객별로 달리 안내합니다.
- 신호등 기준(만원): 일반암 5000, 유사암 1000, 뇌혈관 3000, 허혈 3000, 수술 500, 입원일당 5, 1인실 10, 골절 100. 데이터 JSON의 `recommended` 항목으로 바꿀 수 있습니다.

## API 키 없이 쓰기 (Cloudflare Pages)
브라우저에 키를 입력하지 않고 쓰려면 키를 Cloudflare 서버에 보관합니다. `functions/api/gemini.js`가 Gemini 호출을 대신하므로 키가 브라우저에 노출되지 않습니다.

1. Cloudflare 대시보드 → Workers & Pages → 해당 프로젝트 → **Settings → Variables and Secrets**
2. `GEMINI_API_KEY`를 **Secret** 으로 추가 (Production 과 Preview 모두)
3. (권장) `APP_PASSCODE`도 Secret 으로 추가하면 암호를 아는 사람만 사용할 수 있습니다. 앱이 처음 한 번 암호를 묻고 그 브라우저에 기억합니다.
4. **Deployments → Retry deployment** 로 다시 배포

앱 1번 탭의 **AI 연결 상태** 칸에서 서버 키 연결 여부를 바로 확인할 수 있습니다. 연결되면 키를 입력할 필요가 없고, 안 되면 원인(함수 미배포/키 없음)이 표시됩니다. 서버 함수는 `GEMINI_API_KEY`, `GEMINI_API_KEY_01`, `GEMINI_API_KEY_02`처럼 번호가 붙은 이름과 `GOOGLE_API_KEY` 등을 인식하고, 값 앞뒤 공백·줄바꿈은 자동으로 제거합니다. 키가 여러 개면 번갈아 쓰다가 한도 초과(429) 등이 나면 다른 키로 자동 재시도합니다.

서버 키가 없을 때(예: 파일을 직접 열었을 때)만 **고급: 내 API 키 직접 입력**을 사용하세요.

## 다섯 친구 (소득 기준 필요 보장)
빌더 3번 탭 **기본 정보**의 "다섯 친구" 칸에 직업군과 연소득을 입력하면 고객 리포트 [🚦 보장분석신호등] 탭에 다섯 친구 카드(현재 준비 / 필요 금액)가 두 열로 간단히 표시됩니다. (빌더 기본 정보에서는 '다섯 친구' 칸이 '담당 설계사 정보' 칸 위에 있고, 설계/발행번호·가입 특약 요약 배지 입력은 없어졌습니다.) 기본값은 **근로소득자 · 연소득 5,000만원**이며, 직업군을 '선택 안 함'으로 하고 연소득을 비우면 표시하지 않습니다. (단위: 만원)

| 친구 | 항목 | 필요 금액 |
|---|---|---|
| 첫째 | 병원비 | 연소득 × 1 |
| 둘째 | 생활비 | 연소득 × 1 |
| 셋째 | 부양비 | 연소득 × 2 |
| 넷째 | 법률배상 | 소득과 무관 (시장가격) |
| 다섯째 | 유동자산 | 연소득의 1/10 |

직업군별 기본 연소득: 근로소득자 5,000 · 종합소득자 10,000 · 고소득&순자산증가 15,000 · 법인대표 10,000 · 기초소득자 3,000. 연소득을 직접 입력하면 그 값을 우선 사용합니다. (배우자 연소득·자녀 수 입력은 제거되었습니다.) 같은 값이 상담 대사 생성에도 전달됩니다.

## 다섯 친구 기준 보장분석신호등
소득 정보(다섯 친구 입력)가 있으면 보장분석신호등이 다섯 친구별로 표시됩니다. 없으면 기존처럼 담보 8항목(일반암·유사암·뇌혈관·허혈·수술·입원·1인실·골절) 기준으로 표시합니다.

- 친구별 담보 구성과 권장 금액은 참고 사이트의 '담보별 진단현황' 표를 기준으로 했습니다(아래 참고).
- 각 카드는 **충족한 담보 수**(충분 또는 가입)와 평균 준비율을 보여 줍니다. 신호등은 **기존 + 신규 합산**, 담보별 진단현황은 **기존 계약만** 기준입니다.
- 친구별 상태: 담보별 권장 대비 평균 준비율이 100%면 🟢 충분, 50% 이상이면 🟡 주의, 그 미만이면 🔴 부족, 가입한 담보가 없으면 🔴 미가입. 법률배상은 벌금 · 교통사고처리지원금 · 변호사선임비 · 일상생활배상 중 2개 이상 가입하면 🟢 준비, 아니면 🔴 미비. 유동자산은 보험 서류로 확인할 수 없어 ⚪ 미정보.

## 내 컴퓨터 폴더에 저장 (분석 보관함)
상단 **📂 저장 폴더** 버튼으로 저장할 폴더를 한 번 지정하면, 분석 결과가 저장될 때마다 그 폴더에 `고객명_REC_번호.json` 파일로도 기록됩니다. (같은 고객은 같은 파일을 덮어쓰고, 고객명을 바꾸면 이전 파일은 지워집니다. 한글 이름을 쓸 수 없는 환경에서는 `REC_번호.json`으로 저장합니다.)

- **분석 보관함** 창 아래쪽에서 폴더의 파일 목록을 보고 **불러오기**를 할 수 있습니다. 폴더를 바꾸거나 해제할 수 있고, **보관함 전체 저장**으로 브라우저 보관함의 기존 기록을 폴더에 한꺼번에 저장할 수 있습니다.
- 지정한 폴더는 기억해 두지만, 브라우저를 다시 열면 보안상 접근 권한을 한 번 더 허용해야 합니다. 상단 폴더 버튼이 "(권한 필요)"로 바뀌면 눌러서 허용하세요.
- **데스크톱 Chrome / Edge**에서만 쓸 수 있습니다. (Firefox, Safari, 휴대폰은 지원하지 않으며 기존 브라우저 보관함과 💾 백업저장을 사용하세요.)
- 브라우저 보관함(최대 30건)은 그대로 유지됩니다. 폴더는 추가 저장 위치입니다.
- 폴더의 파일에는 고객 정보가 들어 있으므로 공용 컴퓨터에서는 쓰지 마세요.

## 담보 금액 계산 방식 (계약·비교 / 신호등 / 담보별 진단현황 공통)
세 화면이 같은 계산(`computeCoverage`)을 씁니다.
- 서류를 읽을 때 담보마다 **지급 유형(kind)** 을 분류합니다: 진단비 · 수술비 · 입원일당 · 치료비 · 사망 · 후유장해 · 배상책임 · 기타. (예전 데이터는 담보 이름으로 추정)
- 항목별로 유형이 맞는 담보만 더합니다. 예) '암 진단비'에는 진단비만 포함하고 같은 이름의 수술비·입원일당·치료비는 제외합니다.
- 질병/상해 수술비는 같은 사고에 중복 지급되지 않으므로 **계약마다 가장 큰 담보 하나**만 사용하고 계약끼리는 더합니다. 질병입원일당은 상해입원일당·1인실·간병·암입원 담보를 제외합니다.
- 금액은 **서류에 적힌 글자**(예: "3,000만원")를 우선해 환산하고, AI가 따로 적은 숫자와 다르면 담보 상세에 "⚠️ 금액 확인 필요", 파일 카드에 "금액 확인 N건"으로 표시합니다.
- 감액·면책 기간 중 지급액은 합계에 반영하지 않습니다.

## 담보별 진단현황 (참고 사이트와 같은 구성)
소득 정보가 있으면 담보별 진단현황이 **병원비 · 생활비 · 부양비 · 법률비용 및 기타**(+ 유동자산) 그룹으로 나뉘고, 그룹마다 담보가 막대 줄로 표시됩니다. 담보 줄은 담보명 · 현재 가입금액 · 상태, 권장 금액 대비 막대와 부족 금액으로 구성됩니다. 그룹 제목을 누르면 접고 펼 수 있습니다.

| 그룹 | 담보 (권장 금액, 연소득 5,000만원 기준) |
|---|---|
| 병원비 | 실손의료비 · 3대비급여실손 · 상해수술비(100만) · 질병수술비(100만) · 암수술비(300만) · 뇌혈관질환수술비(2,500만) · 허혈성심장질환수술비(2,500만) · 상해입원일당(3만) · 질병입원일당(3만) · 치아보험 |
| 생활비 | 일반암 진단비(5,000만) · 유사암 진단비(1,000만) · 고액(표적)항암치료비 · 뇌혈관질환/뇌졸중/뇌출혈/허혈성심장질환/급성심근경색 진단비(각 2,500만) |
| 부양비 | 상해사망 · 질병사망(각 1.5억) · 상해/질병 80%미만후유장해(각 5,000만) · 장기요양간병비(3,000만) · 경증치매진단(1억) · 간병인/간호간병 상해·질병 일당(각 20만) |
| 법률비용 및 기타 | 교통사고 벌금(3,500만) · 교통사고 처리지원금(2억) · 교통사고처리 변호사선임비(5,000만) · 일상생활배상책임 가족(자녀)포함 · 화재벌금(2,000만) |

- 권장 금액이 없는 담보(실손의료비, 치아보험 등)는 가입 여부만 표시합니다. 담보 상태: 권장 대비 50% 미만 부족, 50~99% 주의, 100% 이상 충분, 0은 미가입. 부족 금액 = 권장 − 현재.
- 진단·사망·후유장해·치매·뇌/심장 수술비처럼 소득에 비례하는 권장 금액은 연소득에 맞춰 환산합니다(연소득 5,000만원이면 위 표와 같음). 이 환산 방식은 참고 사이트에서 확인하지 못한 가정입니다.
- 담보 이름이 서류마다 조금씩 달라도 맞도록 세 가지로 연결합니다.
  1. **이름 정리**: 무배당·특약·보장·보험금 같은 말과 '(유사암 제외)' 문구, 공백을 지운 뒤 비교합니다.
  2. **AI가 표준 담보명 선택**: 서류를 읽을 때 표의 담보명(31개) 중 가장 같은 것을 담보마다 골라 줍니다(`std`). 골라 준 값이 있으면 그 줄에만 반영합니다.
  3. **분류되지 않은 담보 표시**: 표에 맞는 줄이 없는 담보는 사라지지 않고 담보별 진단현황 맨 아래 **그 밖의 담보**에 이름과 금액으로 표시됩니다.
- 소득 정보가 없으면 담보 8항목 목록이 그대로 표시됩니다.

## 제안 화법 다시 생성 / 고객 리포트 포함 화면 선택
- **화법만 다시 생성:** 서류 분석을 마친 뒤에도 [2. 제안 화법(5종)] 탭에서 서류를 다시 읽지 않고 화법만 새로 만들 수 있습니다. 상황마다 있는 **🔄 다시 생성**은 그 상황의 대사만, **⚡ 화법 5종 모두 다시 생성**은 전부 새로 만듭니다. 계약·권장 금액 대비 현황 숫자를 근거로 쓰며, 분석 결과가 없으면 먼저 서류를 분석하라고 안내합니다.
- **고객 리포트에 포함할 화면:** 오른쪽 미리보기의 **탭 이름 옆 체크박스**(🚦 보장분석신호등 · 📁 계약·담보 현황 · 🏥 실손의료비 · ⚖️ 계약·비교)로 고객에게 보낼 화면을 고릅니다. 체크를 끄면 그 탭이 흐리게 표시되고 안내 문구가 나오며, **다운로드한 고객용 파일(인쇄 포함)** 에서는 해당 탭과 내용이 빠집니다. 체크박스는 미리보기에만 보이고 고객용 파일에는 들어가지 않으며(미리보기에서 인쇄/PDF를 눌러도 체크한 화면만 나옵니다), 선택은 보관함에 함께 저장됩니다. 최소 한 개 화면은 포함해야 합니다.
- **상품별 가입담보 상세**는 기존(보유) 계약만 보여줍니다. 신규 제안 계약의 담보는 ⚖️ 계약·비교 탭에서 확인합니다.
- **실손의료비 구역별 포함 여부:** 미리보기의 🏥 실손의료비 탭에서 **"실손의료비 세대 분석"(세대 선택·세대 설명), "👤 고객 가입 내용", "…→ 5세대 실손으로 바꾸면", "📊 항목별 비교"** 제목 앞의 체크박스로 구역마다 고객 리포트에 넣을지 고릅니다. 체크를 끄면 그 구역이 **고객용 파일과 인쇄/PDF에서 빠지고**(미리보기에서는 흐리게 표시), 맨 위 "고객 실손의료비 가입 세대" 칸은 항상 남습니다. 체크박스는 고객용 파일에는 보이지 않으며 선택은 보관함에 함께 저장됩니다.
- **화법 참고 자료(《통의보감》 전환 화법):** 제안 화법을 만들 때 AI가 '설득하지 말고 통계·의학적 사실로 고객이 스스로 질문하게 만든다'는 원칙과 4단계 틀(의학적 진행 단계 → 국가 통계 → 보유 증권 대조 → 보완 제안), 담보별 논리(암·뇌혈관 깔때기·심장·치매/간병·수술비·혈전용해치료비·산정특례·풀케어 클로징)를 참고합니다. 고객 증권에 실제로 공백이 있는 담보에 해당하는 항목만 골라 쓰며, 금액은 계산된 보장 현황만 사용하고 통계는 근사 표현으로 쓰도록 지시합니다. 참고 자료는 `index.html`의 `TALK_REFERENCE`에서 수정할 수 있습니다.
- **리포트 테마:** 왼쪽 패널의 **[5. 🎨 테마]** 탭에서 고객 화면 색상을 고릅니다(하나만 선택): 기본(현재 색) · 밝은 틸 + 블루 · 블루 네이비(상단만 어둡게) · 밝은 블루. 선택하면 편집 화면(왼쪽 패널·상단)의 색도 함께 바뀌고, 미리보기에 바로 반영되며 선택한 테마는 이 브라우저의 기본 테마로 저장되어 새 화면·보관함 기록·불러오기·화면 비우기 후에도 유지됩니다. 브랜드 로고(IMC)는 모든 테마에서 같은 파란색(#1C39BB)입니다. 신호등 색(충분·주의·부족·미가입)은 테마와 무관하게 그대로입니다.

## 계약·비교의 보장 전·후 비교표 (다섯 친구 담보)
소득 정보가 있으면 계약·비교 탭의 비교분석표가 **병원비 · 생활비 · 부양비 · 법률비용 및 기타** 그룹의 담보(31개)로 표시됩니다. 그룹 제목 줄에는 해당 친구의 상태(신호등과 같은 기준)가 나오고, 담보 줄은 **기존 선택보장 / + 신규 선택추가 / 최종 합산보장** 금액입니다. 담보 이름 앞 점은 합산 기준 상태(🟢 충분·가입, 🟡 주의, 🔴 부족, ⚪ 미가입)입니다. 위쪽에서 기존 계약·신규 계약·담보를 체크하거나 해제하면 표가 바로 다시 계산됩니다. 소득 정보가 없으면 예전처럼 담보 8항목 표가 표시됩니다.

## 브랜드 로고 / 청구 서류 안내
- 고객 리포트 상단 로고 배지와 빌더 화면 왼쪽 위 로고 배지는 항상 **IMC**로 표시되며 바꾸는 입력칸은 없습니다.
- 청구 서류 체크리스트의 세 항목(통원·응급실 / 입원·수술 / 골절·화상·창상봉합술) 모두 **진료비영수증**을 포함합니다.

## 계약·비교 탭의 설계사용 영역
계약·비교 탭의 **기존 가입 계약 목록**과 **새로운 제안 계약 목록**(체크하며 비교하는 영역), 그 사용 안내 문구와 [전체 선택 초기화] 버튼은 설계사가 쓰는 화면이라 **고객용 리포트 파일(인쇄 포함)에는 포함되지 않습니다.** 고객 파일에는 월 보험료 합계와 보장 전·후 비교분석표만 남으며, 표는 설계사가 미리보기에서 체크해 둔 선택 상태를 그대로 반영합니다. 미리보기에서는 이 영역에 "설계사용 화면" 안내가 표시됩니다.
